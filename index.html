    Desk settings

    Titles and colors change the display. The agent’s stable name, provider route and draft ownership stay the same.

    Configuration is not a successful sign-in. Consumer account sign-in is unavailable in this app.

    Use synthetic briefs. Drafts are working text; review them before use.

    Configure providers on this desktop

    Local demo works immediately. Use the Configure Providers launcher to open the terminal setup wizard, then restart the local server. Keys belong in that setup flow, never in briefs or this browser.

    Provider documentation and advanced environment settings:

    • OpenAI: OPENAI_API_KEY + OFFICE_OPENAI_MODEL
    • Claude: ANTHROPIC_API_KEY + OFFICE_ANTHROPIC_MODEL
    • Gemini: GEMINI_API_KEY + OFFICE_GEMINI_MODEL
    • Meta Muse: MODEL_API_KEY + OFFICE_META_MODEL

    Optional OFFICE_OPENAI_MODELS, OFFICE_ANTHROPIC_MODELS, OFFICE_GEMINI_MODELS, or OFFICE_META_MODELS adds comma-separated allowed models. Host configuration does not verify provider access. Consumer account sign-in is unavailable here.
